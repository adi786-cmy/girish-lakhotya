# Open Source & Motion Architecture Attribution

This project incorporates architectural patterns, animation techniques, and interaction concepts derived from open source references:

- **Giats Portfolio** (`https://github.com/Giats2498/giats-portfolio`): Layered visual compositions, mask text reveals, interactive canvas backgrounds, and GSAP animation context patterns.
- **Personal Site Template** (`https://github.com/bt2go/personal-site-template`): Lenis smooth scroll ticker synchronization, ScrollTrigger lifecycle cleanup, scroll-stacked section architecture, and interactive pre-footer concepts.
